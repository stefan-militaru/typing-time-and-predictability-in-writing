<h1>Typing time and predictability in writing</h1>
<h2>Project explanation</h2>
The goal of this project is the implementation of a predictor that models word typing times. The analysis of surprisal scores generated by LLM models on given sentences and the comparison between these and the times recorded by human subjects will be documented in detail. Additionally, many more word-specific features will be extracted from the dataset in order to boost the predictor’s performance. A web interface is also implemented, through which the user can interact with the predictor and view the comparison between their typing behaviour and the one recorded by the BERT LLM model. This project has been developed as part of my bachelor's degree thesis.
<h2>Repo structure</h2>
1. Interface folder - contains the web interface of the project. Can be imported and executed without any additional files.
2. MaskedTokensEmbedding folder - contains the code, results and analysis of the comparison between the two different word masking approaches.
3. ModelTraining folder - contains the code for the model training step of the project.
